# Demas Theme (Sandbox)

This is a custom, no-page-builder WooCommerce block theme, built from scratch as a sandbox/experiment on a throwaway WordPress install (`cornflowerblue-fish-235112.hostingersite.com`) — it is a testbed for the eventual replacement of the Kadence theme on the live demas-group.com site, and nothing from the live site is copied into it.

Architecture, conventions, and forbidden patterns are documented in `CLAUDE.md` at the repo root — start there. Locked content/design reference docs (`demas-homepage-brief.md`, `demas-mega-menu-content-spec.md`, `demas-design-direction.md`, `demas-motion-reference.md`) are also in the repo root and listed in `CLAUDE.md`'s "Design & content reference docs" section.

(The research and reasoning behind the no-page-builder direction originally lived in a doc outside this repo, in a separate planning project — that reference has been removed here since it doesn't resolve from inside this repo. If that background is needed again, it should be copied into this repo rather than linked externally.)
