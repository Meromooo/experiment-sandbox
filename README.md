# Demas Theme (Sandbox)

This is a custom, no-page-builder WooCommerce block theme, built from scratch as a sandbox/experiment on a throwaway WordPress install (`cornflowerblue-fish-235112.hostingersite.com`) — it is a testbed for the eventual replacement of the Kadence theme on the live demas-group.com site, and nothing from the live site is copied into it. For the research and reasoning behind this direction, see `04_site_reference_docs/ai_wordpress_workflow_research.md` in the main Demas WordPress website project.
